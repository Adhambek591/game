# Qırq qız

Browser action game based on the Karakalpak epic «Qırq qız» (Nukus Animation).

- `public/` — the game (static files)
- `wrangler.jsonc` — Cloudflare Worker (static assets) served at https://test.zagara.app

Updates: replace `public/` with the new build and push to `main`; Cloudflare Workers Builds redeploys automatically.
